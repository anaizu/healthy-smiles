# Healthy Smiles

Sitio web de un centro odontológico ficticio, hecho para el curso de Desarrollo Web de Coderhouse.

🔗 **Sitio publicado:**

- Vercel: https://healthy-smiles.vercel.app/
- GitHub Pages: https://anaizu.github.io/healthy-smiles/

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y media queries)
- SCSS (Sass)
- Bootstrap 5
- AOS (animaciones al hacer scroll)
- Git, GitHub, GitHub Pages y Vercel
